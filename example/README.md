# qr_barcode_scanner_example

Interactive studio showcasing all 5 animated viewfinder layouts (`cyberNeon`, `morphingPulse`, `holographicGrid`, `minimalGlass`, and `industrialHud`), real-time 2D QR & 1D Barcode pixel decoding, polygon tracking lock-on, semantic payload parsing, and vector barcode rendering in `qr_barcode_scanner`.

## Run the Example

```bash
cd example
flutter run
```
